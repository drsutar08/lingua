# Lingua screens

Every screen of the app (59 in all), captured from the web build at iPhone size (390 × 844 @2x), mostly with the demo account (`demo@lingua.app` / `Lingua@123`). Store-size versions (1290 × 2796) are in [store/screenshots](../store/screenshots). For a clickable version, open [gallery.html](gallery.html) in a browser.

The speaking screens use simulated speech (the capture browser has no microphone), and the AI conversation screen shows the setup message because no tutor server with an API key was running.
